# 6. 部署与运维文档汇总

本章节涵盖 Kabao 项目的自动化部署脚本、环境配置及 Nginx 网关策略。

## 6.1 部署架构与脚本体系

当前项目基于根目录下的多个 Shell 脚本实现前后端的独立与一键部署。主要分为三类前端项目与单一的后端聚合服务。

### A. 后端部署 (`deploy.sh`)
后端由 Go 编译为单一二进制文件（或使用容器运行）。
*   **执行方式**：运行 `./deploy.sh`
*   **核心逻辑**：
    1.  加载 `.env` 环境变量文件。
    2.  `go build` 编译 `cmd/` 目录下的相关启动入口。
    3.  重启后台常驻进程（可配合 `systemd` 或 `supervisor`）。
    4.  包含必要的数据库平滑迁移 (AutoMigrate) 与检查逻辑。

### B. 前端分发与部署
前端代码位于 `frontend/` 目录，分为 Admin、Merchant 和 User 三个子环境。分别通过以下脚本进行 Vite 打包：
*   **管理端**：`deploy-admin-frontend.sh`
    *   构建产物输出至 `dist-admin/`。
*   **商户端**：`deploy-merchant-frontend.sh`
    *   构建产物输出至 `dist-merchant/`。包含了店长与技师的工作台。
*   **用户端**：`deploy-user-frontend.sh`
    *   构建产物输出至对应目录或供小程序/H5套壳使用。

## 6.2 Nginx 网关与环境配置

项目根目录下提供了基础的 `nginx.conf`，负责请求的代理分发、负载均衡以及前端静态资源的托管。

### A. Nginx 路由策略设计
```nginx
# 伪代码结构示意
server {
    listen 80;
    listen 443 ssl;
    server_name your_domain.com;

    # 后端 API 统一反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        
        # 允许跨域及携带 Header (Authorization 等)
        # add_header 'Access-Control-Allow-Origin' '*';
    }

    # 商户前端托管
    location /merchant/ {
        alias /path/to/kabao/frontend/dist-merchant/;
        try_files $uri $uri/ /index.html;  # Vue Router 历史模式支持
    }

    # 管理前端托管
    location /admin/ {
        alias /path/to/kabao/frontend/dist-admin/;
        try_files $uri $uri/ /index.html;
    }
}
```

### B. 环境变量配置 (`.env` 与 `.env.production`)
*   **后端 `.env`**：包含 MySQL 连接字符串（DSN）、Redis 地址、微信小程序/支付密钥（`APP_ID`, `APP_SECRET` 等）、Token 签名的 `JWT_SECRET`。
*   **前端 `.env.production`**：包含请求后端的 `VITE_API_BASE_URL` 地址，确保在打包时正确替换了开发期的 localhost 地址。

## 6.3 常见运维排错指南
1.  **502 Bad Gateway**：通常是由于后端 Go 服务（默认端口 8080）崩溃或未启动。检查 `logs/` 目录下的应用日志。
2.  **状态机不推进 / 自动结单不生效**：
    *   检查 Scheduler 是否正常随主进程启动。
    *   检查数据库中 `merchant_id` 的状态过滤条件是否被脏数据干扰。
    *   排查死锁：在 MySQL 中使用 `SHOW ENGINE INNODB STATUS` 查看是否有未释放的 `FOR UPDATE` 行锁。
3.  **前端 404 / 刷新白屏**：检查 Nginx 中的 `try_files` 配置是否漏写了指向 `index.html` 的兜底规则（Vue 单页应用标准配置）。
