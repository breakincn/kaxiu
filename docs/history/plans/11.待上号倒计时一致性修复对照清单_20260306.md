# 待上号倒计时一致性修复对照清单（2026-03-06）

## 目标
- 统一“用户卡片详情待上号倒计时”与“客服端叫号管理等待上号”的时间口径。
- 以后端会话状态为准，前端优先使用后端下发剩余秒数。

## 实施结果

### Phase 1：后端统一剩余秒数计算
- 新增统一计算函数：
  - `backend/handlers/session_time_calc.go`
  - `computeStartPendingRemainingSecondsForSession(*models.ServiceSession, now)`
- 规则：
  - 仅 `start_pending` 且未 `start_confirmed_at` 计算；
  - 基准时间 `updated_at`，为空回退 `created_at`；
  - 超时秒数优先 `start_pending_timeout_seconds`，否则回退 `config.StartPendingTimeout()`；
  - 超时或不适用返回 `0`。

### Phase 2：后端接口下发统一字段
- `Usage` 新增兼容字段：
  - `service_session_start_pending_remaining_seconds`
  - 文件：`backend/models/models.go`
- `ServiceSession` 新增兼容字段：
  - `start_pending_remaining_seconds`
  - 文件：`backend/models/service_session.go`
- 接口注入：
  - `GET /merchant/service-sessions`、`GET /merchant/service-sessions/:id`
  - 文件：`backend/handlers/service_session.go`
  - `GET /user/cards/:id/usages` enrichment
  - 文件：`backend/handlers/usage.go`

### Phase 3：前端统一消费口径
- 客服端（Dashboard）：
  - `syncContinueCallBlockedFromPendingSession` 优先读取 `start_pending_remaining_seconds`；
  - 缺失时再回退本地旧算法。
  - 文件：`frontend/src/views/merchant/Dashboard.vue`
- 用户端（CardDetail）：
  - 新增读取 `service_session_start_pending_remaining_seconds`；
  - 叫号 `start_pending` 场景展示 `待上号倒计时 mm:ss`；
  - 多窗口且尚未分配客服时不展示倒计时；
  - 缺失字段时按统一兜底（会话超时秒数或 180 秒）本地计算。
  - 文件：`frontend/src/views/user/CardDetail.vue`

## 测试与验证
- 新增单测：
  - `backend/handlers/session_time_calc_test.go`
  - 覆盖：非待上号、已确认、`updated_at`、`created_at` 回退、超时归零、默认超时回退。
- 回归测试：
  - 在 `backend` 目录执行 `go test ./...`，结果通过。
