## 1. 预检查

- 数据库迁移已执行：
  - `cd backend && go run ./cmd/migrate`
- 后端回归通过：
  - `cd backend && go test ./... -count=1`
- 前端构建通过：
  - `cd frontend && npm run build:user`
  - `cd frontend && npm run build:merchant`

## 2. 商户配置冒烟

### 2.1 预约设置

- 打开商户端“预约设置”
- 确认以下字段可正常读取并保存：
  - 预约前保留缓冲
  - 预约后宽限时间
  - 预约最大等待
  - 预约预测缓冲
  - 预约时段展示粒度
  - 昨天预约可改签到今天/明天阈值
  - 昨天预约仅可改签到明天阈值
  - 系统优化性改签推荐开关
- 打开推荐开关后保存成功
- 重新进入页面，确认开关状态持久化

### 2.2 项目设置

- 打开商户端“项目设置”
- 确认以下字段可正常读取并保存：
  - 拖堂容忍分钟数
  - 拖堂补偿模式
  - 拖堂兑现阈值
  - 固定单位补偿值

## 3. 用户预约主链冒烟

### 3.1 创建预约

- 用户创建明日预约
- 校验预约详情展示：
  - 锁定开始/结束时间
  - 最晚可直接取消时间
  - 当前预约状态
  - 预约项目

### 3.2 改签

- 在阶段 A 获取改签时段
- 确认弹窗显示：
  - 更优于当前
  - 不劣于当前
- 进入阶段 B/C 后重新查看
- 确认仅显示：
  - 更优于当前

### 3.3 系统优化性改签推荐

- 在商户端开启“系统优化性改签推荐”
- 回到用户预约详情页
- 确认出现推荐卡片
- 确认卡片仅展示：
  - 推荐时段
  - 推荐原因
  - 不出现自动改签按钮
- 在商户端关闭开关后刷新用户页
- 确认推荐卡片消失

### 3.4 取消与取消申请

- 在 `5` 小时前取消预约
- 确认直接取消成功
- 在 `5` 小时内取消预约
- 确认进入取消申请而非直接取消
- 商户发起取消申请后
- 确认用户端可：
  - 同意取消
  - 拒绝取消
  - 提交抗辩说明

## 4. 商户履约与结算冒烟

### 4.1 签到建单

- 商户在预约详情或预约列表执行“签到建单”
- 确认预约进入签到/建单后续链路

### 4.2 服务完成

- 完成预约来源服务
- 确认预约结算详情显示：
  - 结算状态
  - 责任归属
  - 原因
  - 拖堂账本
  - 补偿结果

### 4.3 商户取消/失败归责

- 商户直接取消预约
- 确认结算详情出现商户取消原因
- 用户补充抗辩后
- 确认商户端可见用户抗辩

## 5. 不可抗力冒烟

- 用户或商户发起不可抗力申请
- 对方接受
- 确认相关商户违约补偿被撤销
- 对方拒绝
- 确认原补偿保持不变

## 6. 拖堂补偿冒烟

- 构造实际开始时间晚于计划开始时间的预约
- 完成服务
- 确认生成 `appointment_delay_ledgers`
- 达到兑现阈值后
- 确认落到 `appointment_compensations`
- 若为部分兑现
- 确认账本余量仍保留

## 7. 异常修复冒烟

### 7.1 请假影响扫描

- 对已发布可预约排班执行请假确认
- 确认后端能产生：
  - 受影响预约
  - `protected_repair_slots`

### 7.2 商户端异常修复详情

- 打开受影响预约的结算详情
- 点击“异常修复”
- 确认弹层可查看：
  - 受影响预约列表
  - 保护修复槽列表
  - 关联排班信息

### 7.3 保护性改签约束

- 在请假影响场景下查看普通用户改签
- 确认不会抢占 `protected_repair_slots`
- 若无高质量修复方案
- 确认系统提示转取消/取消申请分流

## 8. 月度责任统计冒烟

- 在商户预约详情打开“客服月度异常统计”
- 确认可查看：
  - 请假导致未履约次数
  - 商户免责次数
  - 客服责任次数
  - 首次免责是否已使用
  - 明细账本列表

## 9. 冒烟通过标准

满足以下条件可判定上线冒烟通过：

- 用户预约创建、改签、取消、取消申请、抗辩链路全部可用
- 商户签到建单、结算详情、不可抗力、月度异常统计全部可用
- 拖堂账本与补偿兑现链路正常
- 请假异常修复信息可查看
- 系统优化性改签推荐仅推荐、不自动改签
- 未出现与预约主链直接相关的 4xx/5xx 异常
