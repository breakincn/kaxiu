## 3. 改造线 B：P2 混合项目时长预约重构

### 目标

在客服模式下支持“同一客服绑定多个不同时长项目”，并通过混合时间轴算法生成普通预约、改签和修复推荐所需的候选时段。

### 模式定义

- `technician_grouped`
- `technician_mixed_timeline`

启用混合时间轴必须满足：

- 商户开启客服模式
- 商户显式设置为 `technician_mixed_timeline`
- 客服存在项目绑定，或默认继承商户全部线上可预约项目

### 已完成

- [x] 商户预约设置页已增加 `appointment_scheduling_mode` 显式切换

- [x] 混合时间轴仅在客服模式下可开启
- [x] 商户客服管理页已增加“预约项目”配置入口
- [x] 支持单个专业客服配置可预约项目集合
- [x] 支持“继承商户默认全部线上可预约项目”
- [x] 支持“单独指定项目集合”
- [x] 后端已新增客服可预约项目绑定接口
