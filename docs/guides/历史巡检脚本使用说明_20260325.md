# 历史巡检脚本使用说明

日期：2026-03-25

## 1. 适用场景

用于批量扫描并收口这类历史异常预约：

- 预约状态仍为 `arrived`
- 预约日期已早于今天
- 仍未开始服务（`actual_start_at` 为空）
- 但已经存在到店证据：
  - `actual_arrived_at` 有值
  - 或 `arrived_at` 有值
  - 或已绑定 `usage_id`
  - 或已绑定 `service_session_id`

脚本会把这类预约自动收口为：

- 预约 `failed`
- 核销回滚为 `failed`
- 服务会话取消
- 卡次数回滚
- 自动补建预约结算记录

## 2. 命令位置

命令入口：

- `backend/cmd/repair_cross_day_appointments/main.go`

核心修复逻辑：

- `backend/handlers/appointment.go`

## 3. 使用方法

需要在 `backend/` 目录下执行。

### 3.1 dry-run 先看命中数据

```bash
GOCACHE=/tmp/kabao-go-build-cache go run ./cmd/repair_cross_day_appointments --dry-run=true --limit=200
```

说明：

- `--dry-run=true` 只扫描，不落库
- `--limit=200` 一次最多扫描 200 条

返回示例：

```json
{
  "dry_run": true,
  "count": 2,
  "data": [
    {
      "appointment_id": 68,
      "status": "dry_run",
      "reason": "eligible_for_auto_close"
    }
  ]
}
```

### 3.2 确认后正式执行

```bash
GOCACHE=/tmp/kabao-go-build-cache go run ./cmd/repair_cross_day_appointments --dry-run=false --limit=200
```

返回示例：

```json
{
  "dry_run": false,
  "count": 1,
  "data": [
    {
      "appointment_id": 68,
      "status": "closed",
      "reason": "service_unclosed_cross_day"
    }
  ]
}
```

## 4. 输出字段说明

- `appointment_id`：命中的预约 ID
- `status = dry_run`：仅扫描到，尚未修复
- `status = closed`：已完成自动收口
- `status = error`：修复失败，需要人工排查
- `reason`：本次命中的原因或失败信息

## 5. 推荐执行顺序

每次都建议按下面顺序执行：

1. 先跑 dry-run
2. 核对命中数量和预约 ID
3. 再跑 execute
4. 执行后刷新商户端预约页或再跑一次 dry-run，确认 `count = 0`

## 6. 当前默认规则

- 默认扫描上限：`200`
- 默认修复说明：`系统批量巡检自动结案：跨日未开始服务`
- 只处理“有到店证据”的跨日未开始服务预约
- 不会处理纯 `pending/confirmed` 超时预约

## 7. 注意事项

- 该脚本是正式可重复执行命令，不是一次性 SQL
- 适合开发环境、测试环境、线上环境复用
- 执行前建议确保数据库连接配置 `KABAO_DSN` 正确
- 如果通过 Codex 或受限沙箱执行，可能需要显式指定 `GOCACHE=/tmp/kabao-go-build-cache`

## 8. 验收方式

可用以下 SQL 复查是否还有残留：

```sql
SELECT COUNT(*) AS total
FROM appointments
WHERE status = 'arrived'
  AND appointment_time IS NOT NULL
  AND appointment_time < CURDATE()
  AND actual_start_at IS NULL
  AND (
    actual_arrived_at IS NOT NULL
    OR arrived_at IS NOT NULL
    OR usage_id IS NOT NULL
    OR service_session_id IS NOT NULL
  );
```

如果返回 `0`，说明这类历史脏数据已经清完。
